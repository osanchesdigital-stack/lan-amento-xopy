## 🎓 Glossário

**Supabase**: Backend as a Service (banco de dados + API)  
**RLS**: Row Level Security (segurança por linha)  
**RSVP**: Confirmação de presença  
**Trigger**: Função automática no banco  
**View**: Consulta SQL salva  
**Hook**: Função React reutilizável
